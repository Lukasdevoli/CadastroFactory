# Sistema de Cadastros - Sprint 1 (Projeto estágio)

## Funcionalidades

- ✅ Cadastro de alunos com validação de senha
- ✅ Edição de cadastros 
- ✅ Exclusão de cadastros
- ✅ Armazenamento local com localStorage
- ✅ Interface acolhedora e responsiva

---

## 🛠️ Tecnologias utilizadas no projeto

- HTML 5 
- CSS 3 (Backdrop-filter, flexbox, efeitos visuais)
- JavaScript (Factory method, costructor, functions)
- localStorage para peristência de dados no navegador
